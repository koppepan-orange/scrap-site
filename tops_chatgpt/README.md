# LAST LIGHT - Solo Arena

393px固定幅・真上見下ろし型のソロPvPvEサバイバルTPS試作です。

## 起動

`index.html` をブラウザで開いてください。ローカルサーバー経由でも動作します。外部ライブラリや通信先は使用していません。

## 操作

### PC
- `W A S D` / 矢印キー：移動
- マウス移動：照準
- 左下の武器アイコンを押す：射撃（押し続けると連射）
- `Space`：射撃
- 右下の食べ物アイコンを3秒長押し：HPを最大HPの30%回復
- `H`：同じ回復操作

### スマートフォン
- 左のパッド：移動
- 右のパッド：照準
- 左下の武器アイコン：射撃
- 右下の食べ物アイコンを3秒長押し：回復

食べ物を使用している3秒間は移動できません。食べ物を持っていない場合は回復できません。

## 実装内容

- 12部屋を廊下で接続するランダムマップ。接続部には自動開閉ドアを配置
- 壁で遮られる懐中電灯型の視界。視界外は構造だけ薄暗く表示
- プレイヤー1人＋CPU参加者9人
- 6種類の行動規範を持つCPU。視界判定、壁越し判定、最後に見た位置の記憶（最大10秒）、簡易経路探索を実装
- 近距離・遠距離・自爆・突進の4系統のモンスター
- SMG、SCAR、二丁拳銃、ショットガン、ナイフ、デカハンマー
- マガジン式・自動リロード・5秒間射撃しなかった場合の自動リロード
- モンスター撃破時の食べ物ドロップ
- 240秒かけて縮小する安全地帯。範囲外では毎秒最大HPの5%ダメージ
- プレイヤー死亡後の全景観戦モード

CPUの性格はルールベースの簡易AIです。周囲の全参加者や全アイテムを常時把握することはなく、視界と壁による遮蔽を通して対象を認識します。安全地帯への退避は行動規範より優先されます。

## 画像の登録先

`data.js` の `Images` に、次のフォルダ・ファイル名を登録しています。

- `systems`: `error`
- `weapons`: `smg`, `scar`, `dual_pistols`, `shotgun`, `knife`, `hammer`
- `monsters`: `knocker`, `lamp_eye`, `burst_seed`, `skipper`
- `foods`: `food`

画像ファイルは `.png` で、たとえば `assets/images/weapons/smg.png` に置きます。既存の `komagome.js` の画像ローダーが、読み込みに失敗した画像を `assets/images/systems/error.png` に置き換えます。

この会話に添付されていたのはHTML・JS・CSSの5ファイルで、`assets/` フォルダ自体は含まれていませんでした。そのため、画像がない状態でも遊べるようにCanvasの記号描画を標準にし、画像が読み込めた場合は武器・モンスター・食べ物のスプライトと武器UIへ反映する形にしています。画像がない場合は既存ローダーが `assets/images/systems/error.png` を代替画像として指定します。元のプロジェクトにある `assets/` をこのフォルダへコピーすれば、そのまま読み込めます。

## ファイル構成

- `index.html`：ページ・読み込み順
- `data.js`：画像登録と元データ
- `komagome.js`：元プロジェクトの共通処理・入力・画像ローダー
- `nakami.js`：元プロジェクトの初期化処理
- `mitame.css`：既存CSS＋ゲームUIの追加スタイル
- `game.js`：ゲーム本体
